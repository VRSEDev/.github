# **Overview**

VRSE is an Internet Company based in British Columbia, Canada with the goal of providing a fresh new digital experience with ModuleOS and a network of digital tools for creators to thrive.

**We have four core pillars: Connective, Creative, Ecological, and Diverse. These pillars are the foundation of our company:** 

* We strive to help you be more Connective with your co-workers and partners. 

* We strive to create a highly customizable modular digital environment that puts you into a peak Creative mindset. 

* We strive to help you create a workflow that is Ecological with systems designed to be eco-friendly so your digital productivity does not create anti-productivity towards the environment. 

* We strive to have a Diverse landscape with several customization options and tools at your disposal.

## **The uniVRSE**

* **ModuleOS** \- An open source operating system that is designed to be very modular and customizable. If you don’t like our UI you can rebuild it yourself while keeping our core productivity features and apps. No need to use a VRSE account for our productivity apps, your progress can be saved locally.

* **VRSE Cloud** \- Cloud storage on our server to allow you to create Cloud Drives and host your websites. Because this is directly connected to our servers a VRSE account would be required. This service also allows you to use our productivity network within your browser with no need to install our apps directly to your computer.
